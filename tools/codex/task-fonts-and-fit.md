## 2. Single-line fit (fix TF's regression)
Best fit with wrapping makes short labels break onto two lines ("Hành Tẩu Giang / Hồ" on the Home button and the plaque; "Môn Phái · Cấp / 10" overflowing its plaque). Labels on buttons, plaques, tabs and dropdown captions must stay on **one line** and shrink instead.
- Add a small runtime component, for example `SingleLineFit : MonoBehaviour`. On enable and whenever the text changes, it uses `TextGenerator` / `preferredWidth` to pick the largest font size ≤ the authored size (and ≥ a minimum, around 12) at which the text fits the rect width on one line. Set `horizontalOverflow = Overflow` and turn best fit off for these labels. It must also work in edit mode (builders and snapshots) via `[ExecuteAlways]`, or by an explicit `Fit()` called by the builders.
- Apply it through the TF presets (`OrnateButton`, `Plaque`, `InkBox`), so every preset user gets it.
- Re-check the preset paddings for the sprites; snapshots show these still overlapping the ornaments:
  - the battle buttons "Tạm dừng", "Chơi lại", x1/x2/x4 (`GameplaySceneBuilder` / `ReplayPrefabBuilder` buttons, ~170 px wide; are they built with `UiBuild.Button`? If not, route them through it);
  - the Thương Hội tabs "Đổi nguyên liệu" and "Tiệm Danh Vọng";
  - "Thoát" and "Cài đặt".

  The cloud-scroll ornament takes roughly the outer 18–22% of the button art, so the label rect must stay inside it.
- The locked sect plaque on Home: one line, "Môn Phái · Cấp 10", fitting inside the plaque.
- The fighter title strip in the battle avatar: make sure the title ("Hiệp Khách" / the enemy name) is visible on its strip, with the title font, and fitting on one line.
