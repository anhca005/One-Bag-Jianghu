### Phần 2: battle-engine (giai đoạn 1)
- Tạo `server/` (Maven đa module, Java 17, Maven Wrapper) với module `battle-engine`.
- Mô hình dữ liệu vật phẩm data-driven: 12 `op` hiệu ứng, 8 trạng thái, 8 loại trigger, 12 loại đích. Nạp JSON và kiểm tra lỗi (sai tên trường, sai loại đích, thiếu tham số).
- Lưới Bao Phục: kiểm tra chồng lấn / ra ngoài túi, tính liền kề theo cạnh.
- Vòng lặp trận: tick 100ms, Phổ Công / Tuyệt Kỹ, Hóa Kình, Liệt Hỏa / Kịch Độc / Xuất Huyết / Điều Tức / Định Thân / Trì Trệ / Điểm Huyệt / Khinh Công, Vận Khí, Kiệt Lực, hệ số Trọng, giới hạn độ sâu trigger.
- Nhật ký sự kiện JSON cho client phát lại.
- 14 vật phẩm trong `items.json`, 5 đội hình mẫu trong `samples/`.
- CLI: chạy 1 trận in nhật ký tiếng Việt, tỉ lệ thắng qua N seed, bảng đối đầu. 10.000 trận khoảng 5 giây.
- 23 unit test, tất cả pass.
- Cập nhật docs: `combat.md` (mô tả đúng như code), `items.md` (định dạng JSON đầy đủ), `server/README.md`.
